plus an initial split-chat background/separator application. It contains no

Interpretation:

- Chat reappears solely after hiding IME: prioritize
  `adjustResize`/window insets and responsive RN theatre layout.
- Chat stays absent with IME hidden: prioritize retained mini-player layout
  state / transition condition and theatre navigation callbacks.
- Full chat tree present but invisible: only then look at clipping, z-index,
  overlay order, and Fabric visibility rather than conditional rendering.

For a targeted runtime fix, compare unmodified **31.8.0** smali for the RN
theatre host and minimized-player navigation (see diagnostics README).
Do **not** globally force RN rerender, destroy all chat surfaces, or modify
IRC/emote rendering as a first workaround: those do not address the missing
entire `theatre-chat` subtree and may damage player state.
